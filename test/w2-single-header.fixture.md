# 하네스 위임 머리말 (자동)
- 종류: task / 작업: T01 / 실행 id: fixed-run
- 작업 폴더: /project/wt-T01 — 이 폴더 밖은 읽기만 한다. 파일 변경은 이 폴더 안에서만.
- 샌드박스: workspace-write
- 금지: fodh 실행. git 명령(commit·branch·stash·worktree·push) — 커밋은 하네스가 한다. 전체 테스트 스위트·전체 빌드 실행 — 변경 파일과 직접 관련된 테스트만 실행한다. 비밀값(토큰·키·암호) 출력·기록. 비밀 파일(`.env*`·키·인증 파일) 열기·출력. 배포·업로드·외부 발송. 산출물(zip·빌드 결과·APK) 생성.
- 서브에이전트: 동시 1개 이하, 모델 worker effort high.
- 수용 기준: 아래 스펙의 요구를 모두 만족하고 관련 테스트가 통과한다. 하지 못한 항목은 추정하지 말고 "미완" 으로 적는다.
- 검증: 변경 파일 관련 테스트 + typecheck(있으면). 실행한 명령과 결과 수치를 그대로 적는다.
- 마지막 메시지 형식(반드시): `## 결과` 아래에 (1) 변경 파일 목록 (2) 실행한 검증 명령과 결과 (3) 미완·의문·판단 필요 항목.
