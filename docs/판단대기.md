### A24 — 파일럿 메모리 중단 해제 (rev 1)
- 배경: T01 정리 단계 직전에 스왑이 8GB 기준을 5분 넘게 초과해 하네스가 paused(memory)로 멈췄다(현재 7.8GB). 자동 회복은 6GB 미만 5분이라 Slack·Chrome·오래된 claude 세션 등 사용자 앱을 줄이지 않으면 풀리지 않는다.
- 선택지:
  ① 사용자가 앱을 정리해 자동 회복을 기다린다
  ② fodh memory reset 으로 지금 해제한다(스왑이 안 줄면 5분 뒤 다시 멈춘다)
  ③ 파일럿을 여기서 멈춘다
- 추천: ① 앱 정리 후 자동 회복. 정리 단계는 가볍지만 다음 T02 에서 Codex 를 띄우므로 스왑을 먼저 줄이는 편이 안전하다
- 경과: 22:28 Mac 재부팅으로 스왑 0 → 22:34 하네스가 스스로 회복(memory-recovered)해 T01 정리·T02 까지 끝냈다. 답 1 로 닫으면 된다
- 막힌 작업: -
- 답: 2
