### 문제없음으로 확인

- R2-1: 대입 횟수는 `wholeCommand` 기준이고, `before` 에 `$NAME` 이 있으면 제외한다. `+=`·`read`·`printf -v`(붙인 `-vT` 포함)·`for … in`·`declare -n`·`mapfile`·`getopts`·`unset` 이 원문 어디에 있어도 치환 전체를 끈다(`:56`, `:59`).
- R2-2: TMPDIR 가 바뀌면 `$TMPDIR` 치환(`:113`)과 mktemp 템플릿의 `$TMPDIR` 인정(`:82`)을 모두 끈다. `env -u TMPDIR`·`env -i` 는 목록에 없지만, 값이 비는 방향이라 R3 빈 해석이 받쳐 준다.
- R2-3: 중첩 원문은 해당 원래 토큰이 정확히 `'…'` 한 개일 때만 `tempAllowed` 를 이어받는다. `$()`·백틱 안은 항상 치환하지 않는다(`shell-commands.mjs:134`). 큰따옴표 중첩 안의 작은따옴표 중첩도 false 를 이어받는다.
- R3: `${T}x`·`"$T"x` 처럼 접미가 `/` 가 아닌 형태는 치환하지 않는다. 대입 실패·미실행·서브셸·없는 템플릿 디렉터리는 빈 해석 검사로 막힌다. README 한계 표 문구가 스펙과 같다.
- R10-1/R11: CLI 승인 키 테스트, 보호 조각·환경 파일 거부, `.github`·`.gitignore` 허용 테스트가 모두 통과한다.
