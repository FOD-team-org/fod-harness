## 문제없음으로 확인한 항목

- H1: 53개 `usage` 가 `parseArgs` 옵션과 일치한다. help 는 `resolveCliRoot`·명령 검증·생존 검사 전에 처리되고 부작용이 없으며 두뇌에서도 동작한다. CLAUDE.md 렌더는 group/action 만 쓰므로(`src/core/claude-md.ts:48`) 해시가 바뀌지 않는다.
- H3: `stateAtBrainExit` 를 우선 쓰고, 읽기 실패 시 현재 상태로 폴백한다.
- H5: root 의 revert·cherry-pick·am 은 거부되고, 등록 워크트리의 cwd 나 `-C` 는 허용된다. `cd`·`GIT_DIR`·`--git-dir`·`env -C` 형태는 거부된다.
- H6: 개행을 공백으로 바꾸고, 300자 제한과 `redact` 검사를 거친다. `cell()` 이스케이프가 왕복된다.
- H7·H8: 스펙 문구와 같다.
- H9: id 형식, 내장 이름 충돌, 중복, regex, flags 를 검증한다. 설정 파손 시 두뇌는 fail-closed 이다. `db:generate` 는 허용된다.
- H10: 항목 검증, lstat, 부모 symlink 검사, exclude 중복 방지가 있다. remove·CLEANUP·`du -sk` 는 링크를 따라가지 않는다.
- H2에서 올바르게 거부되는 것: `mktemp -p .`, `--tmpdir=.`, `-t ../x`, root 를 지나는 템플릿, `T=src`, 두 번 대입, 상대 템플릿, `${T}/../..`, `T=/tmp`, `T=/tmp/..<R>`, 임시 루트 자체·root 조상·워크트리·훅 패키지 삭제. `/var/tmp/x /tmp/y` 삭제는 허용되며 이것이 맞다.
