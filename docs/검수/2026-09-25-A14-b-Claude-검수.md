- 평소 작업의 과잉 거부: 31·33·34·35.
- 흔한 문법 `( … ) 2>&1` 을 잘못 읽어 보호 검사를 건너뜀: 32.

모두 좁은 수정으로 닫힌다.

- 원칙 1~4: 들어간 것은 다음과 같다.

  - 사용자·두뇌 공통 토크나이저·glob 수정.
