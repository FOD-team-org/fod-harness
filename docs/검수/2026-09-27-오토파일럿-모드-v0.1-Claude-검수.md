## 문제없음으로 확인한 것

- Pi 프로세스는 `assertNotBrain` 을 통과한다.
- 훅이 오토파일럿 상태 파일을 보호한다(`.pi/harness*.json`).
- 두뇌와 Codex 는 오토파일럿을 켤 수 없다.
- orchestrator 는 PROJECT_READY → PLANNING 전이를 할 수 있다.
- 훅 거부 승인 판단은 `requiresApproval` 로 빠진다.
- 오토파일럿 자신의 쓰기는 `judgment-changed` 를 다시 일으키지 않는다.
- 출처 줄은 `questionHash` 에 영향이 없다.
- DONE_ALL 은 대기한다.
- 스냅샷 마감이 `agent_end` 보다 먼저 일어난다.
