## 문제없음으로 확인한 것

- `setTask` 는 `merge` 를 얕게 합친다. md 들여오기는 숨은 칸을 보존한다. `resume: true` 전이 호출자는 `runPick` 하나다.
- 잠금 순서(`harness-worktree` 단독)는 기존 경로와 겹치지 않는다.
- Codex 자식은 CLI 루트에서 거부되므로(`src/cli/root.ts:9`) `worktree merge` 를 부를 수 없다.
- CLAUDE.md 는 명령 이름만 싣는다. W2 에서 빼도 스냅샷이 유지된다.
- 스테이징된 인덱스가 있으면 `git merge` 가 스스로 거부한다.
- 오토파일럿은 `origin` 없는 새 판단을 건드리지 않는다.
- 한 레포 위임 머리말 바이트 동일은 조건부 줄 삽입으로 가능하다.
- p7-commit·p7-correction8 은 L7 반영으로 영향이 없다.
