## 발견

- **F33 (낮음)** — doctor 의 전역 플러그인 경고가 기본 제공 플러그인에도 뜬다. `src/provider/turn.ts:148` 은 `system.init.plugins[].source` 를 모으고 `src/cli/doctor.ts:46` 은 `source !== 'builtin'` 으로 거르는데, 실제 값은 `agents-md@builtin`·`telemetry@builtin` 이다. 매 doctor 마다 "전역 플러그인 로드 확인" 경고가 뜬다(끌 수 없는 기본 제공). `@builtin` 접미도 걸러야 한다.
- 운영 사고(하네스 결함 아님) — 6 에서 두뇌가 실제 Codex 위임을 시작했는데 그때 사용자의 다른 세션 Codex 가 돌고 있었다(동시 1개 규칙 위반). 하네스 슬롯은 자기 위임만 안다. 10초 만에 `fodh codex cancel` 로 끊었다(읽기만 함, 변경 0). 이후 라이브 시험은 외부 Codex 가 도는 동안 슬롯을 외부 소유로 잡아 두는 감시 스크립트를 쓴다(A14 계획 §1).
- 관찰 — 재개한 haiku 두뇌가 중단 원인을 "codex 위임 실패 감지"라고 적었다(실제로는 SIGINT). 게이트·상태는 하네스 증거로 움직여 영향 없음. 기록만.
