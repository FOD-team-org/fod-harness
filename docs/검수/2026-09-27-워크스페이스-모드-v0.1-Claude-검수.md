- 루트 밖 Bash 쓰기가 지금 통과한다는 v0.1 의 현황 설명(`pretooluse.mjs:143-144`)

- PICK 의존 판정만으로 레포 간 순서가 지켜진다는 점

- DOCS→CLEANUP·CLEANUP→PICK 관문이 워크스페이스 루트 기준이라는 점
- VERIFY cwd 관문이 멤버 워크트리에서도 동작한다는 점
- `rm -rf`·압축 해제 판정이 이미 있다는 점
- 두뇌가 `harness.json` 을 고칠 수 없다는 점
- backend 검증 명령이 AGENTS.md 와 맞는다는 점
- push 가 사용자 몫으로 남는다는 점
