## 새 발견

- **F9 (중간)** 오케스트레이터가 스스로 적용한 인박스 항목이 `delivered` 로 남는다. 위 자동 재개 뒤 `judgment-changed` 는 두뇌가 `fodh inbox ack` 를 하지 않아 세션 재시작 뒤에도 `delivered` 였고, 매 턴 프롬프트에 계속 붙는다. 오케스트레이터가 결정·적용을 끝낸 항목은 오케스트레이터가 직접 `applied` 로 닫아야 한다(두뇌 ack 는 두뇌에게 전달만 된 항목 전용).
- **F10 (관찰)** haiku 두뇌가 IMPLEMENT 에서 P3 자리표시 지시를 무시하고 직접 구현했다(실기 3차에서는 지켰음). P3 `fodh codex` 구현으로 해소 예정, P2 범위 밖.
