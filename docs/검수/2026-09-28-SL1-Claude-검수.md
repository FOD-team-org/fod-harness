## 2차(보정 1) — APPROVE

- F1~F5 스펙대로. 흔한 경우의 새 회귀 없음.
- 실제 ps 에 가장 안쪽 규칙을 적용하면 zsh 래퍼(`eval '… codex-companion.mjs task --cwd …'`)는 빠지고 자식 node 만 남는다.
- Fable 실기: 가짜 companion(`node …/codex-companion.mjs task --cwd "<sp ace proj>/sub"`)을 zsh 래퍼 아래에 띄움(래퍼 cwd = 프로젝트 d).
  - `sp ace proj` 거부, 소유자 = 안쪽 node, root = `…/sp ace proj/sub`
  - d 획득 성공(래퍼 제외)
  - 무관한 프로젝트 a 획득 성공
