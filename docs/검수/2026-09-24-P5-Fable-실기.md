## 3. 발견

- **F1 (중간)** `doctor` 의 `claudeMdLoaded` 판정이 항상 false. Claude Code 2.1.281 의 `system.init` 은 `memory_paths` 를 **객체** `{auto: "<자동 메모리 폴더>"}` 로 보낸다(CLAUDE.md 경로 목록이 아님). `strings(event.memory_paths)` 가 배열이 아니라 `[]` 로 떨어져 매번 `하네스 문서 로드 확인` 경고 알림이 난다. 두뇌는 실제로 CLAUDE.md 를 읽고 있다(`claude -p` 에 검증 명령을 물으면 관리 블록의 `npm test`, `npm run lint` 를 그대로 답함). 수정 방향: (a) `memory_paths` 는 원장 증거로만 남기고(객체면 그대로 기록), (b) `claudeMdLoaded` 는 doctor 프롬프트에 "CLAUDE.md 하네스 관리 블록의 버전 표식(`fodh:managed:begin v1`)이 보이면 `문서 확인 v1` 한 줄을 더 답하라" 를 추가해 응답 텍스트로 판정하거나, 그것이 불안정하면 정적 검사(`<root>/CLAUDE.md` 에 관리 블록 존재 + `claude-md generate --check` 최신)로 대체한다. 경고 알림은 정적 검사 실패 때만.
- **F2 (낮음)** `fodh backlog add --id T01 …` 형태는 없다(`Unknown option '--id'`). 실기 중 내 오용이지만, 알 수 없는 옵션 오류에 해당 명령의 사용법 한 줄을 붙이면 두뇌 재시도가 줄어든다. 선택.
- 관찰: 라운드 2 choice 문항(Q03-02, Q04-01)을 두뇌가 채팅에 선택지로 나열하고 사용자에게 물었다. 프롬프트 규칙 4("choice 문항은 defer") 와 어긋나 보이지만, 사용자에게 먼저 묻고 답이 모호할 때 defer 하는 편이 자연스럽다. 규칙 문구를 "choice 문항은 답이 없거나 모호하면 defer" 로 다듬는 것을 2차에 포함할지 검수 결과와 함께 판단.
