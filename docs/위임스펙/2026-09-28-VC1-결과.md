## 스펙 의도를 유지한 최소 조정

4. 재질문 상한을 `classifyItemAnswer`에서 공통 처리했다. `applyJudgments`만 바꾸면 `completeJudgment`의 잠금 내부 재분류가 같은 답을 거부하기 때문이다. watcher에는 변경이 없고, 복수 번호 답도 기존 자유 서술 60초 안정 대기를 거친다.
5. D4를 지켜 멤버 자리표시에도 hash 일치를 확인한다. 표지 뒤 사용자가 heavy 등을 고친 경우 자동 교체하지 않는다. auto 시각만 달라 init 재시도가 거부되지 않도록 기존 재시도 비교에서 auto.at만 제외한다.
6. 자동 기록기는 잠금 안에서 최신 설정을 다시 검사한다. `detectVerify`가 만든 동결된 객체의 신원도 확인하므로 임의 명령 배열을 만든 내부 호출도 거부한다. CLI에는 명령 문자열을 받는 새 입력이 없다. 기존 `setConfig` 두뇌 거부 및 승인 키 목록은 유지했다.
