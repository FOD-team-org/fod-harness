## 1. 높음 (필수)

### H1. doctor 교착 제거
- `fodh state transition IMPLEMENT|MERGE` 는 doctor 를 **실행하지 않는다**. 대신 `state.doctor.ok === true` 이고 `doctor.checkedAt` 이 12시간 이내면 통과, 아니면 `{ error: "doctor 검증이 없거나 오래되었습니다. Pi 세션을 재시작하거나 fodh doctor 를 실행하세요." }` 로 실패(exit 1). 어떤 경우에도 잠금을 기다리지 않는다.
- `fodh doctor` 는 `.pi/harness.lock` 소유자가 살아 있으면(`isProcessAlive`) **즉시** `{ error: "Pi 세션이 잠금을 보유 중입니다. 세션에서 doctor 가 수행됩니다." }` 로 실패한다. 대기 없음(`waitMs: 0` 상당).
- 테스트: 잠금을 잡은 상태에서 `main(['state','transition','IMPLEMENT'])` 가 1초 이내 반환(저장된 doctor 결과에 따라 성공/실패), `main(['doctor'])` 가 즉시 오류.

### H2. 훅 승인 규칙 축소
- 승인 필수 정규식(`rules`)은 **Bash 의 `command` 문자열에만** 적용한다. `Write/Edit/NotebookEdit` 등 다른 도구 입력에는 적용하지 않는다(비밀값 패턴·보호 경로 규칙은 유지).
- 규칙 평가 전에 `fodh …` 로 시작하는 명령(선행 공백·`npx`·절대경로 `…/bin/fodh` 포함, 파이프·`;`·`&&` 로 다른 명령이 이어지지 않는 단일 명령)은 **전부 통과**시킨다.
- 패턴 축소(설계 §10 16종 취지 유지, 실제 위험 명령 토큰 기준):
  - `prod-migration`: `prisma migrate deploy|reset`, `psql … (drop|truncate|delete)`, `neonctl`, `fodh`가 아닌 `DATABASE_URL=…prod` 등 명령 토큰 기반. 자연어 `production`+`delete` 동시 출현만으로 차단하지 않는다.
  - `payment`, `account-admin`, `paid-resource`, `dns`, `legal`, `external-send`: 명령 실행 토큰(`stripe`, `curl … api.stripe.com`, `gh api … --method (POST|DELETE)`, `slack`/`mcporter … send`, `aws iam`, `gcloud iam`, `vercel domains add`, `certbot` 등)으로만 판정. `legal` 은 Bash 에서 제거하고 문서 편집은 두뇌 규칙(brain-rules)으로만 안내한다.
  - `env-delete`: `vercel env rm|add`, `gh secret set|delete`, `rm … .env*`, `security delete-generic-password` 등 토큰 기반. `unset` 단독은 제외.
  - `push-main`, `prod-deploy`, `store-upload`, `system-settings` 는 현행 유지하되 `[\s\S]*` 를 `[^;|&\n]*` 로 바꾼다.
- 음성 테스트 추가(차단되면 안 되는 것): `fodh judgment add --background "production 데이터 delete 여부"`, `grep -r codex docs/`, `git merge-base main HEAD`, `cat src/hooks/useAuth.ts`, `echo "privacy policy"`, `npm test`, `git log --oneline`, Write 도구로 `docs/설계/결제-설계.md` 에 "subscription create" 문장 작성.
- 양성 테스트(차단되어야 하는 것): `git push origin main`, `git push -f`, `vercel --prod`, `prisma migrate deploy`, `vercel env rm X production`, `gh secret delete X`, `codex exec …`, `c\odex exec`(H9 토큰화 뒤), `launchctl load …`.

### H3. 원장 unknown 종결
- `fodh ledger list [--unknown]` 와 `fodh ledger resolve <runId> <action> ok|fail --evidence "<문장>"` 추가. resolve 는 같은 runId/action 으로 `status: ok|fail`, `evidence: { resolvedBy: 'fodh', note }` 항목을 append 한다(원장은 append-only).
- `runTurn` 의 quota 전환 금지 조건은 "**현재 runId** 의 unknown" 으로 한정한다. 이전 run 의 unknown 은 복구 모드 프롬프트 접두어에만 반영한다.
- 복구 모드 프롬프트에 unknown 항목 목록(runId, action, at)과 `fodh ledger resolve` 사용법을 포함한다.
- `brain-rules.md` 에 "복구 모드에서는 증거 대조 뒤 `fodh ledger resolve …` 로 각 항목을 닫는다" 를 추가.

## 2. 중간 (필수)

### M4. usage 보고와 컴팩션
- `streamClaude` 가 Pi 에 보고하는 usage 는 누적값이 아니라 **마지막 API 호출분**으로 한다: `result.usage` 대신 `result.modelUsage`/`usage.iterations` 가 있으면 마지막 항목의 `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`(문맥 크기)를 `totalTokens`, 없으면 `result.usage` 를 그대로. 값이 없으면 0.
- 확장은 세션 시작 시 Pi 컴팩션을 끄는 방법을 README 에 명시하고(설정 키 `compaction.enabled=false`, Pi 0.73.1 설정 파일 위치 확인), 가능하면 `pi.on('session_start')` 에서 경고를 띄운다(설정 API 로 직접 끌 수 있으면 끈다).
- `[도구 결과]` 표시는 400자에서 자르고 `… (N자 생략)` 를 붙인다.

### M5. redact 안전성과 원장 축소
- `redact` 는 미종료 PEM(`-----BEGIN … PRIVATE KEY-----` 뒤 END 없음)에도 유효한 JSON 을 유지해야 한다. 구현: `safeValue` 는 JSON 문자열 전체가 아니라 **객체를 순회하며 문자열 값마다** `redact` 를 적용한다. `redact` 자체는 문자열 → 문자열이며 예외를 던지지 않는다.
- `AKIA` 패턴은 `\bAKIA[0-9A-Z]{16}\b`. `sk-ant-` 는 유지. GitHub `ghp_[A-Za-z0-9]{36}`, `github_pat_` 추가.
- 원장의 `tool_result` 항목은 전문을 저장하지 않고 `{ tool_use_id, is_error, length, sha256 }` 만 저장한다.
- 테스트: 미종료 PEM 을 포함한 tool_result 이벤트가 protocolError 없이 처리되고 표시 텍스트에 `[비밀값 제거]` 가 있다.

### M6. 과금 사전검사 확장
- `checkBillingEnvironment`: settings 파일들의 `env` 블록 안 `ANTHROPIC_API_KEY|ANTHROPIC_AUTH_TOKEN|ANTHROPIC_BASE_URL|CLAUDE_CODE_USE_BEDROCK|CLAUDE_CODE_USE_VERTEX|CLAUDE_CODE_USE_FOUNDRY` 존재 → configError. 프로세스 env 의 `CLAUDE_CODE_USE_BEDROCK/VERTEX/FOUNDRY` 도 configError. `childEnv` 의 strip 목록에 이 세 키 추가.
- `system.init` 의 `apiKeySource` 가 `'none'` 이 아니면 `billing` 중단(`paused(billing)`)으로 처리하고 원장에 `apiKeySource` 를 남긴다. 가짜 claude 에 `api-key` 시나리오 추가(`apiKeySource: "ANTHROPIC_API_KEY"`).

### M7. 한도 감지 확장
- quota 판정에 추가: `result.is_error && /(rate|usage) limit|limit reached|out of (?:extra )?usage|resets? at/i.test(result.result ?? '')`, `rate_limit_event.rate_limit_info.status === 'rejected'`(즉시 quota, 전환 시도 가능), `result.api_error_status === 429`(현행).
- 가짜 claude `rate-limited` 시나리오를 `result.result` 본문형으로 하나 더 추가(`rate-limited-text`).
- 실물 픽스처는 이번 범위 밖(자연 발생 시 Fable 이 채집).

### M8. doctor 전용 경로
- `doctor()` 는 `runTurn` 을 재사용하되 `doctor: true` 에서: `maxMs` 를 `min(3분, maxTurnMinutes)` 로 제한, **전환(switch) 시도 금지**(quota 면 바로 `configError: quota`), `updateState` 는 `doctor` 필드만 갱신(`sessionId`, `actualModel`, `state`, `rateLimitInfo` 를 건드리지 않음), 인박스 배달 없음(현행).
- 마커 판정은 `tool_input.command` 가 `FODH_DOCTOR_MARKER` 를 **포함**하면 통과(`includes`).
- `session_start`/`model_select` 에서 `state.doctor.checkedAt` 이 12시간 이내이고 `doctor.ok` 면 재실행 없이 `ready = true`. 설정 `brain.doctorTtlHours`(기본 12)로 조정.

### M9. 훅 경로·오탐·우회
- 프로젝트 루트 결정 순서: `FODH_PROJECT_ROOT` env → `CLAUDE_PROJECT_DIR` env → `event.cwd`. `.pi/harness-state.json`·`.pi/harness.json` 은 이 루트 기준. `stream.ts` 는 자식 env 에 `FODH_PROJECT_ROOT=<root>` 를 넣는다.
- 보호 경로는 루트 기준 **절대경로 비교**: `<root>/.claude/settings.json`, `<root>/.claude/settings.local.json`, `<pkg>/hooks/**`, `<root>/.pi/harness*.json(l)`. `src/hooks/useAuth.ts` 같은 일반 파일은 통과.
- git 규칙: 명령을 토큰화(공백·`;`·`&&`·`||`·`|` 분리, 따옴표 처리)해 `git` 토큰 뒤 첫 비옵션 토큰이 `commit|push|merge` 일 때만 적용. `git merge-base`, `git log`, `grep codex` 통과.
- codex 규칙: 토큰 중 하나가 정확히 `codex` 이거나 `*/codex` 로 끝나면 차단. 백슬래시·따옴표를 벗긴 뒤 비교(`c\odex`, `"codex"` 도 차단). `fodh codex …` 는 통과.

### M10. 회수 견고성 (+F1)
- `groupAlive`: `EPERM` 은 **살아있음**으로 취급하고 예외를 던지지 않는다. 그 밖의 오류도 던지지 않고 `/bin/ps -axo pid=,pgid=` 로 재확인한다(ps 실패 시 살아있음으로 간주).
- `reclaimOwnedGroup` 전체를 try/catch 로 감싸 어떤 예외도 밖으로 나가지 않게 하고, 실패 시 `false`(cleaned:false) 를 반환한다.
- 회수 뒤 `child.stdout.destroy()`, `child.stderr.destroy()` 를 호출하고, `closed` 는 최대 10초 타임아웃(`Promise.race`)으로 기다린다. 타임아웃이면 `cleaned:false`.
- ppid 트리 잔존 검사는 P4 로 미룬다(주석으로 남긴다).
- 테스트: 가짜 claude `hang` 시나리오에 "자손을 detach 해 stdout 을 유지" 변형(`hang-orphan`)을 추가해 10초 내 반환·`cleaned` 값 확인.

### M11. fodh 의존성 분리
- `src/cli/*` 가 `@mariozechner/pi-ai` 를 import 하지 않게 한다: `runTurn`·`claudeArgs`·`buildPrompt`·`latestMessage`·`packageRoot` 를 `src/provider/turn.ts`(순수 Node) 로 옮기고, `extensions/provider/stream.ts` 에는 `streamClaude` 만 남긴다. `privacy.ts`, `preflight.ts`, `runner.ts` 도 `src/provider/` 로 이동(확장은 re-export 또는 상대 import).
- 확인: `node --input-type=module -e "import('./src/cli/index.ts')"` 가 pi-ai 없이 성공해야 한다(테스트로 `vi.mock` 없이 import 그래프 검사: `node --experimental-strip-types`… 대신 vitest 에서 `import.meta.resolve` 로 pi-ai 미포함을 단언하거나, 간단히 `src/` 하위 파일 텍스트에 `@mariozechner` 가 없음을 단언).

## 4. Fable 실기 (필수)

- F1: M10 에 포함.
- F2 `templates/brain-rules.md` 를 다음 8줄로 교체(정확한 명령 형식):
  1. 하네스 상태·판단대기·인박스·원장 변경은 `fodh` CLI 로만 한다. 파일을 직접 편집하지 않는다.
  2. 프롬프트 맨 앞 `[인박스 <id>]` 항목은 모두 읽고 반영한 뒤, 턴을 끝내기 전에 반드시 `fodh inbox ack <id> [<id>…]` 를 실행한다.
  3. 승인이 필요한 동작(훅 차단 포함)은 `fodh judgment add --title … --background … --options "a|b" --recommend … --blocks <taskId>` 로 등록하고 그 동작을 시도하지 않는다.
  4. 복구 모드 프롬프트가 오면 증거를 대조하고 `fodh ledger resolve <runId> <action> ok|fail --evidence …` 로 각 항목을 닫는다.
  5. `codex` 를 직접 실행하지 않는다. `fodh codex …` 만 사용한다.
  6. 비밀값을 출력·기록하지 않는다. 승인 필수 동작을 임의로 진행하지 않는다.
  7. 개인정보·약관·결제 정책 문서를 바꿀 때는 판단대기에 먼저 올린다.
  8. 턴 마지막 줄에 `상태: <현재 fodh state>` 를 적는다.
- F3 `judgment.ts` 번호 부여: 문서 전체(열린 판단·보류·결정 완료 표 포함)에서 `A(\d+)` 최대값 + 1. 빈 문서면 A1.
