## 변경 파일 및 선택

변경: `extensions/watcher/index.ts`, `extensions/orchestrator/index.ts`, `src/core/watcher.ts`, `src/core/judgment.ts`, `test/watcher-extension.test.ts`, `test/p2-revision.test.ts`, `test/orchestrator.test.ts`, 이 결과 문서.

- N1의 stat 확인은 최초 ENOENT 이후에만 적용한다. EMFILE 같은 다른 오류는 기존 재시도·경고 정책을 유지한다.
- N4는 모듈 메모리 Set 대신 영속 표식을 쓴다. 이미 처리된 자유 서술 대기 기록은 모듈을 다시 로드해도 반복하지 않는다. 실제 적용 결과 ok는 별도로 기록한다. 표식은 미적용 인박스에 대응하는 동안만 보존한다.
- N3의 최근 200개는 결정 기록 순서다. 요구대로 오래된 미적용 ID도 상한 밖이면 제거되며, 그 항목은 이후 미결정 조회에서 다시 처리될 수 있다. 인박스 자체는 삭제하지 않는다.
- N6는 판단 변경 결정 중의 JudgmentConflict에만 적용한다. 다른 예외는 기존 실패 계수/3회 제한 경로를 유지한다.
