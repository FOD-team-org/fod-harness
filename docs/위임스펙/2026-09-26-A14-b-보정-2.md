## Q1 (중간, 검수 12) — 복합 구문 안의 명령도 같은 검사를 받는다 (`hooks/shell-commands.mjs`)

지금 파서가 내놓는 모양(확인값):

| 입력 | 현재 entries | 문제 |
|---|---|---|
| `f() { prisma migrate deploy; }; f` | `["f()","{","prisma","migrate","deploy"]` | 실행 파일이 `f()` 로 보인다 |
| `function g { prisma migrate deploy; }` | `["function","g","{","prisma",…]` | 실행 파일이 `function` |
| `case "$x" in a) prisma migrate deploy;; b\|c) echo hi;; esac` | `["case","$x","in","a)","prisma",…]`, `["b"]`, `["c)","echo","hi"]` | 실행 파일이 `case`, 패턴 뒤 명령이 안 보인다 |
| `cat <(prisma migrate deploy)` | `["cat","<","(prisma","migrate","deploy)"]` | 프로세스 치환이 재귀되지 않는다 |
| `coproc prisma migrate deploy` | `["coproc","prisma",…]` | 실행 파일이 `coproc` |
| `echo "prisma migrate deploy" \| bash`, `bash <<< "…"`, `bash <<EOF … EOF` | `["bash"]` 등 | 셸이 표준입력으로 명령을 받는다 |

1. **함수 정의** — `unwrap` 이 다음 앞머리를 벗기고, 벗긴 뒤 남은 단어를 보통 명령처럼 검사한다.
   - `NAME()`, `NAME ( )`, `NAME(){`, `function NAME`, `function NAME()`.
   - 벗긴 뒤 이어지는 `{` · `(` 도 기존 규칙대로 벗긴다.
2. **case** — `case WORD in` 은 명령이 아니다. `in` 까지 벗긴다.
   - `case`~`esac` 사이에서 그룹 첫 단어가 `)` 로 끝나면(`a)`, `c)`, `*)`, `(a)`) 그 단어를 패턴으로 보고 벗긴다.
   - 현재 파서는 `b|c)` 를 파이프로 잘라 `["b"]` 를 명령으로 본다. 이 과잉은 그대로 둬도 된다. 다만 패턴 뒤 명령(`echo hi`)은 반드시 검사한다.
   - `;;` · `;&` · `;;&` 는 구분자다.
3. **coproc** — `coproc` 과 선택적 `NAME`(다음이 `{` 일 때만 이름) 을 벗긴다.
4. **프로세스 치환** — `substitutions` 가 작은따옴표 밖의 `<(` · `>(` 를 `$(` 처럼 찾아 재귀 검사한다.
   - 큰따옴표 안에서도 찾아도 된다(과잉 허용).
   - 파서가 `<(` 를 `<` + `(…` 로 나누는 경우도 원문 기준으로 잡는다.
5. **표준입력으로 명령을 받는 셸** — 두뇌에 한해 unresolved(fail-closed)로 거부한다.
   - 조건: 실행 파일 basename 이 `sh` · `bash` · `zsh` · `dash` · `ksh` 중 하나이고, `-c` 가 없으며, 옵션을 뺀 인자가 없거나 `-` · `-s` · `/dev/stdin` 뿐이다. 파이프 뒤·heredoc·here-string·`<` 리다이렉트 여부는 따지지 않는다. 두뇌는 대화형 셸을 쓰지 않는다.
   - `source` · `.` 의 인자가 `/dev/stdin` · `/dev/fd/*` · `-` · 프로세스 치환이면 같은 처리.
   - 거부 문구: `표준입력으로 셸에 명령을 넘기는 형태는 검사할 수 없습니다. bash -c '…' 로 쓰세요`, 라벨 `경계`.
   - README 의 알려진 한계 "heredoc 으로 셸에 넘긴 문자열은 검사하지 않는다" 를 이 규칙에 맞게 고친다. 스크립트 **파일** 실행은 계속 한계로 남긴다.
   - 인터프리터(`node`·`python`·`python3`·`perl`·`ruby`·`bun`·`deno`·`php`·`osascript`)가 프로그램을 표준입력으로 받는 형태도 다룬다. 조건은 스크립트 인자가 없거나 `-`·`/dev/stdin` 인 경우다(`python3 - <<EOF`, `node <<< "…"`, `… | python3 -`). 두뇌에 한해, R10 의 인라인 인터프리터 검사(보호 경로·판단 파일 언급)를 heredoc 본문·here-string 을 포함한 원문 전체에 적용한다.
6. **테스트** (`test/a14b.test.ts`) — 위 표의 입력마다 두 가지를 확인한다.
   - README 예시 승인 규칙(`prisma migrate deploy`)으로 거부된다.
   - 같은 구조에 `rm -rf src` 를 넣으면 경계로 거부된다.
   - 사용자(두뇌 아님) 판정은 바뀌지 않는다.
   - 과잉 거부 확인: `f() { echo hi; }; f`, `case $x in a) echo a;; esac`, `diff <(cat a) <(cat b)` 는 두뇌에게 허용된다.
   - A14 원래 명령 4개(`test/hook.test.ts` 562~570 근처)는 계속 허용된다.

## Q3 (높음, 검수 14·18) — 임시 변수는 나열이 아니라 fail-closed 로 (`hooks/temp-paths.mjs:53-59`)

재바인딩 형태를 나열하는 방식(`rebinding` 정규식, `read|unset` 검사)을 버리고, 다음 두 조건을 **모두** 만족할 때만 NAME 을 임시 변수로 인정한다.

1. **맨 이름 1회**
   - 최상위 원문 전체(중첩·따옴표·heredoc 포함)에서 NAME 이 식별자로 나오는 곳을 센다.
   - 식별자로 친다: 앞뒤가 `[A-Za-z0-9_]` 가 아닌 NAME 중 바로 앞이 `$` 가 아니고, `${`·`${#`·`${!` 뒤도 아닌 것.
   - 이 횟수가 정확히 1이어야 하고, 그 1회는 인정하려는 `NAME=` 대입이어야 한다.
   - 이 규칙이 잡는 것: `NAME[0]=`, `readarray NAME`, zsh `for NAME (…)`, `print -v NAME`, `select NAME`, `(( NAME = 1 ))`, `let "NAME = 1"`, `declare -n R=NAME`, 다른 대입 등.
   - 과잉 거부(커밋 메시지 안의 NAME 글자 등)는 HEAD 판정으로 돌아가는 것이므로 받아들인다.
2. **이름을 동적으로 만드는 형태가 원문 어디에도 없다.** 하나라도 있으면 그 명령에서는 임시 변수(`TMPDIR` 치환 포함)를 전부 끈다.
   - `eval`, `source`, `.`(명령 위치)
   - `let`, `((`, `$((`, `[[`
   - `${` 안의 `[`(배열 첨자 = 산술 평가)
   - `$'`(ANSI-C 따옴표)
   - `export`·`declare`·`typeset`·`local`·`readonly`·`integer`·`float` 의 인자 중 옵션이 아니면서 이름 부분(`=` 앞, `=` 이 없으면 전체)이 리터럴 식별자가 아닌 것(`$`·백틱·따옴표 연결)
   - `read`·`mapfile`·`readarray`·`getopts`·`select`·`coproc`·`trap` 명령, `printf -v`·`print -v`
   - 함수 정의, heredoc·here-string
3. `test/hook.test.ts` 의 `a14TempCommands` 10개는 계속 허용된다. 예: `export EXPENSE_DATA_DIR=$D` 는 이름 부분이 리터럴이므로 2 에 걸리지 않는다.
4. 테스트: 검수 14 의 형태를 두뇌 거부 회귀로 넣는다. 형태마다 뒤에 `rm -rf "$NAME"` 와 `echo x > "$NAME"` 를 붙인다. 검수 18 의 과잉 거부 해소도 확인한다: `unset CI` 나 `--title "… read …"` 가 같이 있어도 NAME 과 무관하면 예외가 유지돼야 한다.

   - 보호 대상: `.pi` 직속 `harness*.json(l)`, `.claude/settings*.json`, 훅 디렉터리, extraProtected, 그리고 Q7 의 셸 시작 파일

3. `tar -x`·`unzip`·`ditto -x`·`bsdtar -x` 추출 목적지가 `.claude`·훅 디렉터리이면 거부한다. `.pi` 는 지금 규칙을 유지한다.
