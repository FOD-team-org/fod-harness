## (b) 필수 — `agent_end` 자동 재개 (조사 §3-1)

0.75.4 부터 확장 `agent_end` 를 run 안에서 await 하므로 그동안 `ctx.isIdle()` 이 항상 false 다. 지금 `autoResume(…, 'agent_end')`(`extensions/orchestrator/index.ts:260·273·282`)는 늘 `skipped:'busy'` 로 끝나 하네스가 멈춘다.

1. `autoResume` 이 `reason === 'agent_end'` 일 때는 유휴 검사 두 곳(`resume.ts` 잠금 전·후)을 건너뛴다. 대신 `ctx.hasPendingMessages?.()` 가 참이면(사용자가 턴 중에 입력을 큐에 넣었다) `{ skipped: 'pending-input' }` 으로 끝낸다. 사용자 입력이 다음 턴을 연다. `ResumeContext` 에 `hasPendingMessages` 를 추가한다(없으면 false).
2. 보내는 방식은 지금처럼 `{ triggerTurn: true, deliverAs: 'followUp' }`. streaming 중 followUp 은 Pi 가 run 끝에서 이어 붙인다(조사 §3-1 안 A, 공식 plan-mode 예제와 같다).
3. 다른 경로(워처 타이머·judgment-changed·codex-done·slot-free·recover)는 유휴 검사를 그대로 둔다. run 이 active 인 동안 그 경로는 busy 로 막혀 두 번 보내지 않는다.
4. 0.73.1 로 되돌려도 같은 코드가 동작해야 한다(0.73.1 은 agent_end 때 이미 idle 일 수 있다 — 그때도 followUp 1회).
5. 테스트: 가짜 ctx 가 `agent_end` 중 `isIdle: () => false` 를 돌려줄 때 재개 1회(`sendMessage` 옵션 확인); `hasPendingMessages: () => true` 면 재개 없음 + 원장/결과 `pending-input`; 워처 경로는 `isIdle false` 면 여전히 busy. 기존 agent_end 재개 테스트는 새 조건에서도 통과해야 한다.

## (c) 권장 — `session_shutdown` 대기 상한 (조사 §4-3)

0.77.0 부터 SIGHUP·SIGTERM 이 `session_shutdown` 을 기다리는 정상 종료다. 우리 대기에 상한이 없으면 터미널이 닫힌 뒤 Pi 가 좀비가 될 수 있다.

1. provider `session_shutdown`(`extensions/provider/index.ts` `await pending`)과 watcher(`extensions/watcher/index.ts:120·137` `await pending; await memoryPending`)의 대기를 `Promise.race` 로 5초 상한. 상한에 걸리면 원장 `shutdown:timeout`(evidence `{ extension, waitedMs }`)을 남기고 잠금 해제·정리를 계속한다. 상한은 코드 상수(설정 아님).
2. 테스트: 끝나지 않는 pending 에서 5초(테스트는 주입 가능한 짧은 값) 뒤 잠금 해제·원장 1회.

## (d) 권장 — 컴팩션 안내와 문구

1. `extensions/provider/index.ts:85` 의 무조건 경고를 조건부로: `~/.pi/agent/settings.json`(환경변수 `PI_CODING_AGENT_DIR` 가 있으면 그 아래) 또는 프로젝트 `.pi/settings.json` 에서 `compaction.enabled === false` 를 읽으면 경고하지 않는다. 읽기 실패·키 없음이면 지금 문구로 경고하되 "0.79 부터 프로젝트 설정은 신뢰 전에는 무시되므로 전역 `~/.pi/agent/settings.json` 을 권장" 을 붙인다.
2. `src/provider/shutdown.ts:24` 주석: 0.73.1 SIGHUP 동기 종료, 0.77+ 정상 종료를 함께 적고 "맨 앞 위치는 회수를 가장 먼저 하기 위해서" 로 고친다.
3. README "Pi 컴팩션 설정" 절: 전역 설정 권장, 프로젝트 신뢰 설명 한 줄, 실행 레시피에 `PI_SKIP_VERSION_CHECK=1`(자동 업데이트 조회 끔) 한 줄.
