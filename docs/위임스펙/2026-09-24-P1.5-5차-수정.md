## 1. 자식 PATH 에 패키지 `bin` 선두 삽입 (필수)

- `childEnv()`(또는 `runTurn` 의 env 조립)에서 `PATH = <packageRoot>/bin:<기존 PATH>` 로 설정한다. `packageRoot` 는 `src/provider/turn.ts` 의 값. `bin/fodh` 는 실행 권한(0755)이 있어야 하며 저장소에 그렇게 기록되어 있는지 확인(`ls -l bin/fodh`; 아니면 결과 문서에 적는다 — chmod 는 해도 된다).
- `bin/fodh` 는 Node 24 의 타입 스트리핑으로 `.ts` 를 직접 import 한다. 자식의 `node` 가 nvm 경로라 PATH 상속만으로 충분하지만, `FODH_NODE` env 가 있으면 훅과 같은 규칙으로 그것을 우선하도록 `bin/fodh` 셔뱅 대신 작은 sh 래퍼가 필요하면 추가한다(선택).
- 테스트: 가짜 claude 가 `fodh inbox ack` 를 실제 실행(PATH 로 해석)하는 시나리오 `ack` 추가 → 턴 종료 뒤 인박스 `applied`. `childEnv().PATH` 가 `<packageRoot>/bin` 으로 시작함을 단언.
