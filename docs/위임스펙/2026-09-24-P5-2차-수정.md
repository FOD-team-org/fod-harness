## 중간 (필수)

**M1 `interview next` 멱등화(호출 횟수 ≠ 물은 횟수)** — `src/core/interview.ts`, `templates/prompts/INTERVIEW.md`, `test/interview.test.ts`
- 검수안 ① 채택. 상태 파일에 `openRound: { round, ids[] }` 를 둔다. `next` 는 `openRound` 가 있고 그 문항 중 `record`·`defer`·`skip` 된 것이 하나도 없으면 **같은 문항을 askCount 증가 없이** 그대로 돌려준다(`{round, questions, repeated:true}`). 하나라도 처리됐으면 openRound 를 해제하고 새 라운드를 뽑는다(남은 미처리 문항은 askCount 유지, 다음 라운드에 다시 포함 가능).
- `record`·`defer`·`skip` 이 openRound 의 문항을 처리하면 그 ID 를 openRound.ids 에서 뺀다. 비면 해제.
- 사용자 채팅 입력이 왔을 때(오케스트레이터 input 훅, 상태 INTERVIEW) `openRound` 를 해제하지 **않는다** — 답이 record 로 들어와야 진행이므로, 답 없는 입력(예: "잠깐만")으로 한도가 소진되면 안 된다. 즉 askCount 는 "다른 라운드가 뽑힐 때 아직 미처리로 남아 다시 포함될 때"만 는다.
- 테스트 33-35 를 "답 없는 연속 next 는 같은 라운드 반환·askCount 1 유지" 로 바꾸고, 1개만 record 뒤 next → 새 라운드에 미처리 5개가 askCount 2 로 포함되는지, 두 번 미처리 후 mustDefer 로 넘어가는지 검증.
- INTERVIEW.md 3번: "`fodh interview next`로 다음 라운드를 받는다(답 없이 다시 부르면 같은 라운드가 온다. 그때는 다시 묻지 말고 `대기: 사용자`로 멈춘다)".
