## npm install 및 의존성 상태

- 승인된 `npm install --offline --no-audit --no-fund`를 **1회 실행했으나 실패(exit 255)**했다. 기존 `node_modules/typescript`는 전역 설치본을 가리키는 링크이며, npm의 `chmod node_modules/typescript/bin/tsserver`가 샌드박스 `EPERM`으로 거부됐다. 네트워크 요청은 없었다.
- 이 시도는 초기 baseline 수집 중 기존 package-lock.json이 없어서 준비 스크립트가 중단된 뒤, 아직 이름 교체 전 package.json으로 실행됐다. 따라서 새 의존성 설정의 npm 설치 완료로 계산하지 않는다. 이후 이름·경로 교체는 완료했고, 설치 명령은 재시도하지 않았다.
- 검증을 위해 저장소 `node_modules/@earendil-works/` 아래에 실제 전역 0.87.1 설치본을 가리키는 로컬 심볼릭 링크 두 개만 생성했다. 외부 설치본의 권한이나 내용을 바꾸지 않았다. 테스트·최종 typecheck는 이 새 이름 링크를 사용했다.
- **package-lock.json은 작업 시작·종료 모두 없음. 설치·lockfile 갱신 완료는 미확인.** Fable이 새 package.json 기준으로 위 오프라인 설치 명령을 실행하고 결과를 확인해야 한다. 전역 설치 및 사용자 compaction 설정 완료는 사용자가 제공한 전제이며 이 에이전트가 재실행하지 않았다.
