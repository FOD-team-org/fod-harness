# SL1 프로젝트별 슬롯 구현 결과

## 요약

D1~D6을 유지했다. 하네스 루트마다 `<root>/.pi/harness-slots.json`과 그 파일 잠금을 사용한다. 프로젝트 안의 Codex·heavy 배타는 유지하고 프로젝트 간 점유는 분리했다. 워크스페이스는 루트 하나의 슬롯을 공유한다. 전역 슬롯 파일을 읽거나 쓰거나 이관하지 않으며 `FODH_SLOTS_DIR` 지원을 제거했다. 머신 전체 상한과 메모리 정책은 변경하지 않았다.

외부 후보 필터는 그대로 두고 모든 후보를 검사한다. 절대·상대 경로 인자와 주입 가능한 cwd 조회, realpath 및 없는 경로의 기존 조상 정규화, 루트·멤버·prefix 디렉터리·등록 워크트리 영역을 적용했다. 위치 모름은 기존 redact 후 200자 원장, 스캔·영역 실패는 실패 원장을 남긴다. 오래된 다른 프로젝트 대기 표지는 현재 파일이 비어 있으면 해제한다.

최종 실행 기준 관련 9개 파일에서 **183개 통과**, 이름 필터로 **47개 미실행**. 새 SL1 테스트 **38개 통과**. `npm run typecheck`와 `git diff --check` 통과. 전체 테스트, Git 커밋·브랜치 생성, 실제 제공자 실행은 하지 않았다.

## 남은 한계

- 실제 머신의 외부 Codex·`ps`·`lsof` 감지와 실시간 60초 경과는 미검증이다. 새 감지 테스트는 전부 스냅샷/cwd 주입이며, 60초는 watcher의 `now` 주입으로 검증했다. 기존 보조 진단의 best-effort 프로세스 조회 성공 여부는 증거로 사용하지 않았다.
- 실제 Git 커밋·브랜치를 생성하는 `test/a14c-setup.test.ts`, W2 헬퍼를 쓰는 통합 테스트, 실제 프로세스 트리 회수가 필요한 감독 수명 테스트 등은 실행하지 않았다. `test/verify.test.ts`, `test/cleanup.test.ts`, `test/p7-launcher-timeout.test.ts`도 이번 실행 목록에 포함하지 않았다. 이 파일들의 수정은 경로/API 변경이며 타입 검사는 통과했다. 전체 스위트는 스펙대로 Claude 검수 범위다.
- `listWorktrees(root)`는 하네스 상태의 `worktrees`와 Git의 `porcelain`을 함께 반환한다. “등록 워크트리”를 보수적으로 해석하여 두 종류의 경로를 모두 포함했다. 상태에 남은 아직 없는 경로도 prospective realpath로 포함한다. Git 조회 실패를 이 함수가 `error` 필드로 반환해도 사용 가능한 상태 등록·루트·멤버·prefix 영역은 유지한다(비-Git 프로젝트도 지원). 함수가 throw하거나 다른 영역 계산이 실패하면 §3-2대로 실패 원장 후 루트 하나만 사용한다.
- 설정 자체가 깨져 externalGuard 값을 읽을 수 없으면 guard 활성으로 간주하고 실패 원장 후 루트 하나만 검사한다. 설정 오류를 이유로 전역 범위를 적용하지 않는다.
- 위치 옵션이 여러 개면 명령 순서상 첫 번째 옵션을 사용한다. ps 명령 문자열은 원래 argv 경계를 완전히 보존하지 않을 수 있으며, 위치 조회·정규화 실패는 위치 모름으로 기록하고 세지 않는다. 없는 경로 정규화는 config의 기존 private helper와 같은 알고리즘을 슬롯 파일 안에 두어 변경 범위를 유지했다.
- 외부 감지는 획득 직전 스냅샷이다. 이후 시작하거나 cwd를 바꾼 외부 프로세스까지 예약하지 않는다. cwd 조회는 후보마다 최대 1초이며 후보가 많으면 합산 지연이 생길 수 있다. 머신 전체 동시성 상한은 D5대로 추가하지 않았다.
- `externalCodex()`의 기존 첫 후보 API는 호환을 위해 유지하고 슬롯 경로만 새 `externalCodexCandidates()`로 모든 후보를 검사한다. 후보 필터 조건은 바꾸지 않았다.
- 시작 시 이미 수정되어 있던 `docs/설계/2026-09-24-하네스-설계-v0.3.md`, `docs/설계/2026-09-27-워크스페이스-모드-v0.2.md`와 위임 스펙 원문은 수정하지 않았다. 커밋·브랜치 생성과 실제 제공자·네트워크 호출은 하지 않았다.

최종 상태 확인 중 별도 생성된 `.DS_Store`, `extensions/.DS_Store`, `skills/.DS_Store`, `src/.DS_Store`가 관찰되었다. 작업 산출물로 취급하지 않고 수정·삭제하지 않았다. 결과 문서의 13개 기존 테스트 파일·57개 변경 블록은 실제 diff와 대조했고 필수 절 누락이 없음을 확인했다.
