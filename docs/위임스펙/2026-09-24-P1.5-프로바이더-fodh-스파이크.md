## 3. 수용 기준 (vitest, `npm test` 로 전부 통과)

1. `state.ts`: 동시 쓰기 10회에도 파일이 깨지지 않고 마지막 값 보존, 잠금 stale(죽은 pid) 회수.
2. `judgment.ts`: 픽스처 `test/fixtures/judgment/*.md` 로 파싱 — 열린 항목·rev·답, 답 분류 6종(§4-3 표: 번호/번호+조건/자유서술/부정·유보·모순/rev 불일치/빈값). 결정 완료 표 이동 시 원문·해석 보존. 자기 저장 후 기대 해시 반환.
3. `inbox.ts`: 3항목 queued → 한 턴 프롬프트에 순서대로 포함 → ack 로 applied → 재시작 후 applied 아닌 것만 다시 포함.
4. provider `first`: Pi 스트림에 text 델타가 순서대로 나오고 tool_use 는 표시용 텍스트로만(`toolCall` 이벤트 0건), `done(reason:"stop")`, 상태 파일에 `sessionId`, 원장에 `system.init.model`·`usage`·`permission_denials` 1건 → 판단대기 항목 자동 생성(제목에 도구명·명령 포함), 같은 denial 재발 시 항목 1개 유지.
5. provider `resume`: 두 번째 턴 명령에 `--resume <같은 sid>` 가 들어간다.
6. provider `overage`: abort, state `paused(billing)`, 알림 훅(콜백) 1회.
7. provider `rate-limited`: 가짜 switch 명령 1회 실행 후 재시도 1회, 두 번째도 실패면 `paused(quota)`. 원장에 `unknown` 이 있으면 switch 하지 않고 `recovering`.
8. provider `hang`: `maxTurnMinutes` 를 테스트에서 초 단위로 줄여 deadline 초과 → 그룹 종료 → 손자 프로세스까지 잔존 0 → state `recovering` → 다음 프롬프트 첫 줄이 "복구 모드" 로 시작.
9. provider `no-verbose`: 설정 오류로 분류(`configError`), 재시도 없음.
10. `fodh doctor`: env 에 `ANTHROPIC_API_KEY` 가 있으면 실패 JSON, 없으면 통과. 훅 실제 차단 시험은 `brain.command` 를 가짜 claude 로 바꿔 수행(denial 1건 확인).
11. `hooks/pretooluse.sh`: 셸 테스트(vitest 에서 spawn) — `codex exec …` 거부, `.claude/settings.json` 편집 거부, 비밀값 패턴(`sk-ant-`, `AKIA`, `-----BEGIN … PRIVATE KEY`) 거부, 상태 IMPLEMENT 에서 `git commit` 거부·MERGE 에서 허용, 평범한 `ls` 허용.
12. `npm run typecheck`(tsc --noEmit) 오류 0, `npm run lint` 없으면 생략.

## 4. 제약

- 비밀값·계정·토큰을 코드·테스트·문서에 쓰지 않는다. 실제 `claude`·`cswap`·`codex` 를 테스트에서 실행하지 않는다.
- 의존성 최소: TypeScript, vitest, `@mariozechner/pi-coding-agent`(타입은 전역 설치본 `/Users/minseok/.nvm/versions/node/v24.13.1/lib/node_modules/@mariozechner/pi-coding-agent` 를 `file:` 또는 devDependency 로 참조 — 복사 금지), `proper-lockfile` 정도. Node 24.
- `node_modules` 는 커밋하지 않는다(.gitignore). 빌드 산출물 남기지 않는다. 전체 테스트 외 다른 프로젝트의 테스트를 돌리지 않는다.
- Pi API 는 문서로 확인한 것만 쓴다: `docs/extensions.md`, `docs/custom-provider.md`(streamSimple·createAssistantMessageEventStream), `docs/packages.md`. 확실치 않은 API 는 결과 보고 "미확인" 에 적고 우회한다.
- `pi install` 은 실행하지 않는다(Fable 이 한다).
- 코드 주석·CLI 메시지는 한국어, 식별자는 영어.
