### M1 (중간) — glob 훅 규칙이 `codex` 가 든 정상 명령을 거부한다 (`hooks/pretooluse.mjs:278-279`)

`/[*?\[]/.test(word) && /plugins\/cache|codex/.test(word)` 가 체인 안 모든 단어에 적용되어 `fodh codex task --title "codex 위임 확인?"`, `fodh judgment add --title "codex 슬롯이 부족한가?"`, `grep "codex.*task"`, `find -name '*codex*'` 가 거부되고, `find … -exec node` 는 대상이 `node` 이기만 하면 무조건 거부된다(512e1d1 대비 회귀).

1. glob 검사는 **실행 대상 위치**로 한정한다: 실행 파일(`args[0]`), 인터프리터(`node|bun|deno|python*`) 바로 뒤의 첫 스크립트 인자(옵션 제외), `find … -exec/-execdir/-ok <cmd> <첫 인자>` 의 `<cmd>` 와 첫 인자. 그 위치의 단어에 glob 문자와 `plugins/cache` 또는 `codex-companion` 이 함께 들어 있을 때만 거부(`codex` 단독은 제외 — 예: `*codex*` 는 companion 이 아니면 통과).
2. `find -exec` 대상이 `node` 인 경우 1 의 스크립트 인자 규칙으로만 판정하고, 대상이 `codex|claude|cswap` 이면 기존대로 거부.
3. 테스트: 위 정상 명령 5건 허용, `node ~/.claude/plugins/cache/*/codex/*/scripts/codex-comp*.mjs task`·`find ~/.claude/plugins -name "*companion.mjs" -exec node {} task \;` 거부 유지.

### M2 (중간) — 사용자 턴 수락이 넛지 사례(라이브 01:18 F28·PICK F25)를 다시 연다 (`extensions/orchestrator/index.ts:86, 221-225`)

결정: **명시적 멈춤만 수락한다.** (a) 새 명령 `/hold` 를 등록해 state `userHold: true` 를 세운다(알림 `다음 두뇌 턴의 대기: 사용자 를 받습니다`). (b) `input` 이벤트(source ≠ extension)의 텍스트가 멈춤 의도 어휘 — `멈춰|멈추|기다려|잠깐|보류|확인할게|확인하고|stop|hold|wait|pause` (단어 경계 또는 한글 어절 시작; 대소문자 무시) — 를 포함하면 `userHold: true`. 진행 어휘(`진행|계속|해줘|go|continue`) 는 세우지 않고, 두 부류가 함께 있으면 멈춤이 이긴다. `userTurn` 표지는 `userHold` 로 대체한다(이름 변경; 기존 테스트 갱신). (c) `agent_end`: F25·F28 판정 **뒤에** 수락 분기를 두되, `userHold` 가 참이면 거부하지 않고 `awaitingUser` 를 세우며 `turn:user-wait-accepted`(evidence `{ state, taskId, hold: 'command'|'input' }`) 를 남긴다. `userHold` 는 어떤 `agent_end` 든 끝에서(finally) 지우고, `input` 이벤트 뒤 `prompt()` 예외로 `agent_end` 가 안 오는 경우를 위해 다음 `input` 이벤트에서도 먼저 지운다(10차 참고 "userTurn 고착"). (d) 두뇌가 `대기: 사용자` 없이 정상 진행하면 `userHold` 는 그냥 소멸.
테스트: "진행해" 넛지 + `대기: 사용자` → `turn:user-wait-rejected`·재개(01:18 라이브 재현); "잠깐 멈춰, 내가 확인할게" + `대기: 사용자` → 수락·`hold: 'input'`; `/hold` 뒤 extension 재개 턴 + `대기: 사용자` → 수락·`hold: 'command'`; PICK + "계속" + `대기: 사용자` → `pick:user-wait-rejected`.
