## 1. 배경

사용자 방침(2026-09-27): "사용량은 cswap 이 관리한다." 하네스는 사용량을 판단하지 않는다.

- cswap(claude-swap 0.26)은 메뉴바에서 자동 전환 엔진을 돌린다.
  - 5시간·7일 사용률 중 높은 값이 임계(기본 90%)를 넘으면, 여유가 가장 큰 계정으로 미리 바꾼다. 확인 주기는 기본 60초다.
- 지금 하네스는 두 가지를 따로 한다. 둘 다 cswap 과 겹친다.
  1. `rate_limit_event` 의 초과 사용 신호로 `paused(billing)` 에 들어간다. RL1 오판(사용량 경고 이벤트)의 원인이다.
  2. 한도 오류가 나면 `brain.switchCommand`(기본 `cswap switch`)를 직접 실행하고 1회 재시도한다.
     - 인자 없는 `cswap switch` 는 다음 계정으로 차례대로 돈다. 한도에 걸린 계정도 건너뛰지 않는다.
     - 그래서 자동 전환이 고른 계정을 덮어쓸 수 있다.
- 남기는 것은 API 키 과금 경로 차단이다. 사용량이 아니라 결제 경로(구독 로그인 vs API 종량)를 보는 검사다.
  - 시작 전 검사: `src/provider/preflight.ts` `checkBillingEnvironment`
  - 실행 중 검사: `system.init.apiKeySource !== 'none'` → `billing`

## 2. 변경

### 2-1. 판정

`src/provider/rate-limit.ts` 의 `rateLimitVerdict(info)`:

| 조건 | 결과 |
|---|---|
| info 가 객체이고 `status === 'rejected'` | `quota` |
| 그 밖(초과 사용 필드·모르는 status·객체 아님 포함 전부) | `continue` |

- 반환 형은 `'continue' | 'quota'` 로 좁힌다.
- `turn.ts` 의 `patchState({ rateLimitInfo })` 기록은 그대로 둔다. `/status` 표시용이다.
- `rate_limit_event` 로는 이제 `billing` 이 나오지 않는다.

### 2-2. 한도 분기(`turn.ts` 333-352 부근)

- 계정 전환과 재시도를 뺀다. `brain.switchCommand` 를 실행하지 않고, 원장에 `switch` 항목을 남기지 않는다.
- 한도일 때의 순서는 이렇다.
  1. doctor 면 지금처럼 `configError: quota` 를 돌려준다.
  2. 이번 run 에 unknown 원장 항목이 있으면 지금처럼 `recovering` 으로 간다.
  3. 그 밖에는 `paused(quota)` 로 두고 `{ reason: 'error', classification: 'quota' }` 를 돌려준다.
- 재시도는 기존 PICK 백오프가 맡는다(5·15·60분, 3회 뒤 판단). 그 사이 cswap 이 계정을 바꾼다.
- `attempt` 반복문이 필요 없어지면 정리해도 된다. 단 한도가 아닌 경로의 동작은 바이트 단위로 같아야 한다(원장 항목·상태·반환값).

### 2-3. 설정 키

- `brain.switchCommand` 는 설정 읽기·검증·승인 전용 키 목록에 그대로 둔다. 기존 설정 파일과 테스트 설정과의 호환 때문이다.
- 코드는 이 값을 쓰지 않는다.
- README 209행 승인 전용 키 설명에서 `brain.switchCommand` 뒤에 `(RL2부터 쓰지 않음, 호환용)` 을 붙인다.

### 2-4. billing 문구

billing 은 이제 API 키 경로에서만 난다. 문구를 그에 맞춘다.

| 위치 | 새 문구 |
|---|---|
| `turn.ts` billing 알림 | `API 키 과금 경로를 감지해 두뇌를 멈췄습니다. 구독 로그인으로 실행되는지 확인하세요(apiKeySource).` |
| `doctor.ts` `doctorFailureMessage('billing')` | `configError: billing — 두뇌가 구독 로그인이 아니라 API 키로 실행됐습니다. API 키 환경변수·apiKeyHelper 를 확인하세요` |

- quota 문구와 그 밖의 문구는 그대로 둔다.
- `pick.ts` 의 사유 문구도 그대로 둔다.

### 2-5. 그대로 두는 것

- 훅이 두뇌의 `cswap` 직접 실행을 거부하는 규칙
- `preflight.ts`
- `/status` 의 `rateLimit` 표시
- `templates/`·`skills/`·`hooks/`·`docs/설계/`
