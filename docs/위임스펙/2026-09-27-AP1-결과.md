## 2. 결정 1~3 반영

1. **열거 기대값만 확장:** 기존 테스트 변경은 아래 한 줄뿐이다. 다른 기존 테스트·훅·설계 파일은 작업 전 SHA-256과 일치한다. 이 한 줄을 원래대로 환원한 문자열의 해시도 원본과 일치함을 확인했다.
2. **출처 곁 파일:** 판단 Markdown에 `fodh-origin`을 쓰지 않는다. CLI 등록 반환값에도 origin을 추가하지 않아 `judgment add` JSON을 유지한다. 인터뷰의 추천 글은 바꾸지 않고, 추천과 첫 선택지의 정규화 결과가 같거나 기본 선택지 쌍이면 `recommendedOption`이 1을 반환한다. 출처 곁 파일과 오토파일럿 상태 파일의 쓰기를 기존 훅이 거부하는 테스트를 추가했다.
3. **CLAUDE.md 유지:** autopilot 명령은 CLI 명령표에만 추가하고 CLAUDE.md 생성 목록에서 제외했다. 두뇌 안내는 `instruction()` 앞 줄로 전달한다. `test/w1-claude-md.test.ts`의 기존 고정 스냅샷 2개가 무수정으로 통과했다.

## 5. 스펙과 다른 점 및 구현상 보완

- 원본 §1의 Markdown 출처·인터뷰 추천 번호 변경은 **후속 결정 2로 대체**했다. §7의 생성 명령 목록은 **결정 3**을 따랐다. 기존 테스트 수정은 **결정 1**의 한 줄만 적용했다.
- Pi 연결 코드를 `extensions/orchestrator/autopilot.ts`로 분리했다. 코어의 Pi 비의존성을 유지하고 watcher 연결을 독립적으로 검사하기 위한 내부 분리다.
- 상태 파일에 `runId`, `pendingApply`, `failedApply`, `doneAll`, chat 진척 정보를 추가했다. 재활성화된 세션 구분, 정확한 재시도 대상, 실패 기록, 1회 알림 및 CLI 판단 적용에 따른 회신 계수 초기화를 위한 내부 정보다. `pendingApply`에는 판단 원문 대신 SHA-256을 저장한다.
- `PLANNING`은 실제 상태 코드상 `phase: task`일 수 있으므로 상태 이름으로 회신을 허용한다. task REVIEW는 제외한다.
- 기존 수동 답 번호 분류는 10까지다. 11번째 이상도 추천할 수 있는 요구를 충족하도록 **해시가 유효한 자동 답에만** 선택지 번호 분류를 확장했다. 수동 답 분류는 유지했다.
- 유예 훑기는 별도 타이머를 만들지 않는다. 합쳐진 watcher tick에서는 이미 요청된 전체 tick을 먼저 처리한다.
- 꺼짐·만료·한도 중단을 적용 재시도보다 우선한다. 마지막 허용 답의 적용이 경합하면 모드는 꺼지고 이미 쓴 답은 보존한다. 해당 경계는 새 테스트로 고정했다.

## 6. 남긴 한계

- 실제 Pi 대화창·실제 모델·macOS 알림은 실행하지 않았다. 가짜 Pi·가짜 두뇌·알림 비활성화 검증이다.
- 차단 낱말은 보수적이므로 기획 판단도 수동으로 남을 수 있다. 추천 품질 자체는 검증하지 않는다.
- 출처가 없거나 손상된 기존 판단은 자동으로 답하지 않는다. 완료된 출처 항목은 곁 파일에 유지하며 자동 용량 정리는 넣지 않았다.
- 명시적 off·기간 만료·한도 도달과 적용 경합이 겹치면 이미 쓴 답이 남을 수 있다. 사용자가 `/judged <번호>`로 확인·적용한다.
- 판단 파일·상태·원장의 다중 파일 쓰기 도중 강제 종료나 디스크 장애에 대한 복구 시험은 하지 않았다.

작업 중 git 명령, 네트워크 접근, 실제 claude·codex·cswap·pi·osascript 실행을 하지 않았다. 기존 테스트가 임시 저장소에서 수행하는 git만 허용된 범위로 실행되었다. 실제 비밀 파일을 열거나 비밀값을 출력·기록하지 않았다.

### 차이와 남은 한계

- 검수 요청에서 제외하거나 미룬 항목은 없다. 기존 답을 보존하는 동작은 유지하고, 미적용 번호를 조회 시점에 계산한다. 이는 §5·§6에 기록된 미적용 답의 수동 확인 한계를 보완한다.
- 실 Pi·모델·macOS 알림, 다중 파일 쓰기 중 강제 종료·디스크 장애는 이번에도 실행·검증하지 않았다. 가짜 Pi·주입 시계·알림 전달 함수로 검증했다.
- 기존 원장의 반복 알림 줄을 소급 삭제하지 않는다. 확장된 `drop\w*` 등의 보수적 차단은 관련 일반 단어도 수동 확인 대상으로 남길 수 있다.
- git 명령·네트워크·실제 claude/codex/pi/osascript·전체 테스트 스위트는 실행하지 않았다. 기존 테스트 내부의 임시 저장소 git만 허용 범위로 실행했다.
