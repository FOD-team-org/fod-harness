## 남긴 한계와 실행 범위

- `/bin/ps`가 차단되어 **신규 sh → sleep 2.5 → exec node 통합 1건**, **기존 cleanup의 실제 시작 시각 기반 회수 1건**은 skip했다. 주입 시각·token 및 mock 경로는 통과했다. ps 가능한 환경에서 두 실물 테스트 확인이 남는다.
- 실제 claude/codex/cswap/pi 및 실제 osascript, 네트워크는 실행하지 않았다. 실제 Pi 화면·실제 Claude 스트림의 실기 확인은 남는다. UI는 주입 객체, 두뇌는 가짜 Node 명령으로 검증했다.
- 다른 PID에 대해 ps가 불가능하면 기존 signal 0 기반의 보수적 생존 판정을 유지한다. 현재 프로세스 소유 판정은 token 집합으로 해결한다.
- 전체 스위트는 금지에 따라 미실행. 작업 저장소 git 명령·커밋·branch·stash·add 없이 진행했고, `docs/설계/`는 수정하지 않았다. README 수정은 U1-6 화면 출력 절에 한정했다.
