## V1 (높음, 42) — 치환 안 heredoc (`hooks/shell-parts.mjs:20-35`, `:69-72`)

1. `expansionEnd` 가 치환 안의 heredoc 을 처리한다.
   - `<<`·`<<-` 뒤 구분자를 기억한다. 구분자에 붙은 따옴표·백슬래시는 벗겨서 비교한다.
   - 다음 줄부터 구분자와 같은 줄까지 본문을 건너뛴다. `<<-` 이면 앞 탭을 떼고 비교한다.
   - `<<<`(here-string)와 `$((…))` 산술 안의 `<<` 는 heredoc 이 아니다.
2. `expansionEnd` 는 V2 의 주석 규칙도 적용한다.
3. 끝(`)`·백틱)을 못 찾으면 `text.length` 를 돌려주지 않고 "닫히지 않음" 을 돌려준다. 그때는 이렇게 한다.
   - U1 분기를 타지 않는다. U1 이전처럼 문자 단위로 계속 토큰화한다.
   - 두뇌는 unresolved 로 둔다.
4. 사후 감사(`src/core/audit.ts`)도 같은 토크나이저를 쓰므로 같이 고쳐진다. 감사 테스트 1건을 넣는다.
5. 테스트:
   - 사용자 거부:
     - `git commit -m "$(cat <<'EOF'⏎fix: don't crash⏎EOF⏎)" && git push origin main` (승인)
     - 같은 형태 뒤 `&& echo x > .pi/harness.json` (보호)
     - 메시지 `fix: user's bug` 뒤 `; npx prisma migrate deploy` (README 예시 규칙)
     - 메시지 `fix (see below` 뒤 푸시
     - `x=$(cat <<'EOF'⏎don't⏎EOF⏎); echo x > .pi/harness.json`
   - 두뇌 허용(DOCS 상태): `git commit -m "$(cat <<'EOF'⏎docs: fix today's log⏎EOF⏎)"`
   - 두뇌 거부: 같은 형태 뒤 `&& rm -rf src`

## V2 (높음, 43) — `#` 주석 (`hooks/shell-parts.mjs:64-118`, `:20-35`)

1. `shellParts` 에서 다음 조건의 `#` 를 만나면 줄바꿈 직전까지 건너뛴다.
   - 따옴표·치환·산술 밖이다.
   - 단어가 시작되기 전(`!started`)이다. 곧 줄 첫머리, 공백 뒤, `;`·`|`·`&`·`(`·`)` 같은 연산자 뒤다.
2. 줄바꿈은 지금처럼 구분자로 처리한다.
3. `expansionEnd` 안에서도 같은 규칙으로 건너뛴다.
4. 단어 안의 `#` 는 영향이 없다: `$#`·`${#x}`·`a#b`·`issue#12`.
5. 테스트:
   - 사용자·두뇌 거부: 검수 43 ①② 재현 전부
   - 두뇌 허용: `npm test # don't care`, `# don't worry⏎npm test`, `echo "a # b"`, `echo x#y`
   - 감사 테스트 1건

## V6 (참고, 48①) — 치환이 섞인 쓰기 경로 (`hooks/pretooluse.mjs:439-445`)

1. 쓰기 목적지에 따옴표 밖 `$…`·`${…}`·`$(…)`·백틱이 섞여 있고, 임시 변수로 치환되지 않았다고 하자. 그러면 각 동적 조각을 **한 경로 조각 와일드카드** `[^/]*` 로 바꿔 P7 패턴 판정에 태운다.
   - 사용자: 보호 경로와 비교한다.
   - 두뇌: 보호 경로, 판단 파일, 시작 파일과 비교한다.
2. 맞으면 해당 문구로 거부한다.
3. 맞지 않으면 지금 판정대로 간다. P8 의 프로젝트 밖 동적 경로 거부, U8 의 상대 경로 판정.
4. 동적 조각 하나만으로 된 목적지(`> $X`, `> "$LOG"`)는 `[^/]*` 가 최상위 파일에만 맞는다. 보호 경로는 모두 하위 디렉터리에 있으므로 사용자 판정은 바뀌지 않는다.
5. 테스트:
   - 사용자·두뇌 거부: `echo x > .pi/harness.json$(true)`, `echo x > .pi/$X`, `echo x > $D/settings.json` (사용자는 `.claude/settings.json` 과 맞으면 거부. 경로 조각 하나라 `$D` = `.claude` 에 맞는다)
   - 사용자 허용: `echo x > "$LOG"`, `npm test | tee test-$(date +%s).log`
   - 두뇌 허용: `echo x > docs/$(date +%F)-note.md`
