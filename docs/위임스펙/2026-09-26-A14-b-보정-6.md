## W1 (중간, 49·50·51) — 동적 목적지는 정적 글자가 가리킬 때만 보호 대상과 맞춘다 (`hooks/pretooluse.mjs:196-213`, `:294-301`, `:353`, `hooks/path-patterns.mjs:22`)

V6 은 동적 조각을 `*` 로 바꿔 보호 대상과 대조했다. 이 때문에 정적 글자가 전혀 없는 목적지(`"$DEST"`, `"$D/$F"`)나 확장자만 정적인 목적지(`docs/$NAME.md`)까지 보호 대상과 맞아 과잉 거부가 났다.

1. **동적 패턴에만 쓰는 추가 조건.** 리터럴 glob 과 동적이 아닌 목적지 판정은 바꾸지 않는다. 동적 패턴 `P` 가 대상 `T` 와 regex 로 맞더라도, 아래 (a)·(b) 가운데 하나가 참일 때만 "맞음" 으로 친다. 대상은 보호 후보, 가드 디렉터리, 시작 파일·디렉터리, 판단 파일이다.
   - (a) **마지막 조각이 구체적이다.** `P` 의 마지막 경로 조각이 "와일드카드 하나 + 선택적 확장자 하나"(`/^\*(?:\.[^./*?\[]+)?$/`)가 아니다.
     - 구체적이다: `harness.json*`, `판단대기*.md`, `.zsh*`, `settings.json`, `.pi`, `*-notes.md`
     - 구체적이지 않다: `*`, `*.md`, `*.json`
   - (b) **가드·시작 디렉터리가 정적으로 적혀 있다.** 명령에 적힌 `P` 의 디렉터리 조각 가운데 하나가 정적(와일드카드 없음)이다. 그 조각이 `T` 의 가드 디렉터리 이름이나 시작 디렉터리 이름과 같다. 가드 디렉터리는 `guardDirectories`, 시작 디렉터리는 `startupDirectories` 다.
     - 예: `.pi/$X`, `.claude/$F`, `.pi/$X.json`
     - `root`·`HOME`·`~` 를 풀어서 붙은 앞부분 조각은 "적힌 조각" 이 아니다.
2. **복사 목적지 분기.** cp·mv·install·ditto·rsync·ln 목적지가 가드 디렉터리와 맞는지 보는 분기(`:206-209`)도 위 조건을 따른다.
   - `cp x "$DEST"` 는 조건을 만족하지 않으므로 이 분기를 타지 않는다.
   - `cp -r x "$D/.pi"` 는 마지막 조각 `.pi` 가 구체적이므로 분기를 탄다.
3. **조건을 만족하지 않을 때.** 동적 패턴 판정을 건너뛰고 보정 4 까지의 판정(HEAD `feda350` 판정)을 그대로 쓴다.
   - 두뇌의 프로젝트 밖 동적 경로 거부(P8), U8 상대 경로 판정은 그대로다.
4. **테스트.**
   - 사용자 허용(HEAD 와 같음)
     - 49·50 재현 전부: `cp README.md "$DEST"`, `cp README.md "$DEST/"`, `mv a "$DEST"`, `cp -r src "$OUT"`, `rsync -a src/ "$BACKUP/"`, `install -m 755 bin/x "$BIN"`, `cp a.txt "$1"`, `cp README.md "$(mktemp -d)"`
     - 51 재현: `echo x > "$D/$F"`, `echo x | tee "$D/$F"`, `for f in a b; do cp "$f" "$OUT/$f"; done`
   - 두뇌 허용
     - `echo x > docs/${TOPIC}.md`, `touch docs/$NAME.md`, `cp README.md docs/$NAME.md`, `cat > docs/$NAME.md <<EOF⏎x⏎EOF`
     - 보정 5 허용 목록 유지: `docs/$(date +%F)-note.md`, `.pi/scratch/$NAME.md`
   - 사용자·두뇌 거부 유지
     - `echo x > .pi/harness.json$(true)`, `echo x > .pi/$X`, `echo x > .pi/$X.json`, `echo x > $D/settings.json`
     - `cp a.txt "$D/harness.json"`, `cp x .pi/$X`, `cp -r x "$D/.pi"`
   - 두뇌 거부 유지: `docs/판단대기$X.md`, `~/.zsh$X`
     - `>> ~/$F` 는 문구가 달라져도 거부면 된다(P8 동적 경로).
   - 보정 5 의 `test/a14b-r5.test.ts` 기대가 위와 어긋나면 이 스펙에 맞춰 고친다. 결과 문서에 줄마다 근거를 적는다.

## W2 (참고, 54) — V5 문구 범위 (`hooks/pretooluse.mjs:291-293`)

1. V5 문구(`임시 변수 예외를 줄 수 없는 조합…`)를 쓰는 경우는 하나다. 대상 변수 이름이 같은 명령 안에서 대입된 이름일 때다(`NAME=…`·`export NAME=…`·`read`·`for NAME in` 등, 기존 대입 탐지 재사용).
2. `$HOME`·`$PWD`·`$OLDPWD`·`$TMPDIR`·대입되지 않은 이름은 기존 경계 문구로 돌린다.
3. 판정(거부)은 바뀌지 않는다.
4. 테스트 2건: `T=$(mktemp -d); cp README.md "$T"/; rm -rf "$T"` → V5 문구. `rm -rf "$HOME"` → 기존 문구.

## W4 (README) — 한계 표 (52·53·51①·55②)

- "변수·인용·경로 확장" 행에 더한다.
  - W1 규칙: 동적 목적지는 마지막 조각이 구체적이거나 가드·시작 디렉터리가 정적으로 적혔을 때만 보호 대상과 대조한다. 모든 조각이 동적인 목적지는 보호 대상과 대조하지 않는다.
  - zsh 글롭 플래그(`(#i)` 등, extended_glob)는 검사하지 않는다.
  - 확인된 임시 변수 뒤에 동적 조각이 붙은 목적지(`"$T/$f"`)는 임시 경로로 치환하지 않는다. 두뇌는 거부한다.
- 주석 행(없으면 새로)에 적는다: 공백 없이 `)` 뒤에 붙은 `#`(`(npm test)# …`)는 주석으로 보지 않는다.
- 사후 감사 행에 적는다: 괄호에 붙은 fd(`)2>&1`) 앞 경로가 `unresolved` 목록에 잡음으로 남을 수 있다(판정에는 영향 없음).
