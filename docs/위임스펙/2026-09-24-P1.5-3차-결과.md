## 설계 판단·범위와 재검증

1. **ps 불가 시 C 문자열을 만들어 내지 않는다.** 정상 조회만 C 원문이고, 조회 불가 레지스트리는 기존 `spawn:ISO` 표식이다. 시작 시각을 확인하지 못했다는 사실을 보존한다. 잠금 파일의 기존 ISO 시작 시각도 C ps 출력과 파싱 비교할 수 있고, 기존 파싱 불가 문자열은 원문 비교한다.
2. **Pi 선택과 파일 설정의 일관성:** model_select는 상태뿐 아니라 harness.json의 brain.model에도 저장한다. 이후 매 턴 파일 설정을 다시 읽으므로 Pi 선택, CLI 변경, 직접 편집 모두 다음 턴에 반영된다. 대화 세션 ID는 바꾸지 않는다. 실제 Pi TUI의 모델 표시 전환 실기는 실행하지 않았다.
3. **설정 해석:** 기본값은 키가 없을 때만 적용한다. 새 모델·정수·effort 필드에 잘못된 null/타입/범위를 주면 검증 실패한다. 점 키의 빈 구성요소와 prototype 관련 키, 객체가 아닌 중간 경로는 오류로 처리한다. 설정에 없는 다른 프로젝트 키는 보존한다.
4. **위임과 회전:** 새 delegate 필드와 rotateAtTokens는 설정 계약만 구현했다. 실제 Codex 위임(P2)·보조 회전 실행으로 범위를 확대하지 않았다. 사용자 Claude 설정 파일은 편집하지 않았다.
5. **외부 재검증 필요:** 스펙이 허용한 샌드박스 관찰 실패 35개가 남았다. Fable은 ps/프로세스 관찰이 허용된 환경에서 동일한 `npm test`와 `npm run typecheck`로 전체 통과를 확인해야 한다. 이 재검증도 가짜 Claude만으로 가능하다.

실행 금지 조건 준수: git(status/diff 포함), 실제 claude/cswap/codex 실행, 비밀값 추가, 커밋 모두 하지 않았다. 서브에이전트는 동시에 1개만 사용했다.
