# 판단대기 항목 형식 참고

항목은 `fodh judgment add --title "<제목>" --background "<배경>" --options "선택1|선택2" --recommend "<추천>" --blocks - [--detail <문서>]`로만 등록한다. 이 파일은 scaffold 대상이 아니다. 배경은 두 문장 안으로 쓴다.

### A12 — 제목 (rev 1)
- 배경: 결정이 필요한 이유
- 선택지:
  ① 선택 1
  ② 선택 2
- 추천: ① — 추천 이유
- 막힌 작업: T07 또는 -
- 자세히: [비교.md](조사/비교.md)
- 답:

`## 한눈에`는 열린 판단의 번호·제목·막힌 작업·추천을 하네스가 다시 만든다. 답은 각 항목의 `- 답:`에만 쓴다.
`## 최근 결정`은 최근 결정 N줄(기본 5)과 기록 링크다. 두 절의 수동 편집은 다음 하네스 쓰기 때 덮어쓴다.

완료된 항목은 판단 파일 디렉터리의 `판단기록/YYYY-MM.md`에 KST 결정일 기준으로 옮긴다.
질문 원문과 답 원문, 해석, 반영, 결정일을 함께 기록하며 판단기록은 하네스만 쓴다.
